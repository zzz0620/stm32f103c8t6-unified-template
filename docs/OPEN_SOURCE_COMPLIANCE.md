# 开源许可评估与发布清单

> 这是基于仓库内容的工程合规分析，不构成法律意见。

## 结论

第一份压缩包包含完整 GNU Affero General Public License version 3 文本，且嵌入的 Git 元数据显示来源为：

`https://gitee.com/yang-changzhi11/NUN_DX_STM32F1c8t6__-open-source-library.git`

因此可以进行二次开发并公开发布，但本整合作品涉及对该代码的修改和组合，稳妥做法是让整个公开仓库继续采用 GNU AGPL v3，提供完整对应源码、构建/安装所需文件，保留原作者和许可证声明，并清楚标注修改。若通过网络向用户提供该程序的交互服务，还要遵守 AGPL 的网络源码提供义务。

仅有通用 `LICENSE` 文本、没有单独出现 “or any later version” 的明确授权声明时，本仓库不自行推断可升级到后续版本，故标记为 **AGPL-3.0-only**。

## 第二份工程的限制

第二份 `rm2026-dartloadcell-stm32` 没有发现顶层许可证。无许可证不等于公共领域，也不自动允许第三方公开再分发。

本仓库能公开上传的前提是以下至少一项成立：

1. GitHub 发布账号持有人是第二份工程全部原创代码的著作权人；或
2. 已从相应权利人获得允许以 AGPL-3.0-only 公开和再分发的授权。

如果无法确认，必须在公开发布前移除或替换第二份工程的原创部分，不能仅靠补一个 LICENSE 解决。

## 第三方代码

- STM32F1 HAL：随 STM32CubeF1 包的条款；包外使用时其 `LICENSE.txt` 指向 BSD-3-Clause。
- CMSIS Core/Device：Apache-2.0 或文件中随附的 ST 条款。
- FreeRTOS Kernel：MIT。
- ZDT Emm_V5 示例在源码注释中标注了原作者/商家，但未发现单独许可证；发布者已于 2026-09-29 明确确认拥有公开和再分发权利。建议长期保存相应授权凭据。

完整路径和版本见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。
