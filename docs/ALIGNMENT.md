# 需求对齐记录

## 2026-09-29

- 目标不是仅能编译的示例，而是可实际部署和上板维护的 STM32F103C8T6 模板。
- 对外接口要简洁，业务代码不直接依赖大量 CubeMX 句柄和任务全局变量。
- 模块之间不要过度耦合；采用中央功能开关、稳定 facade 和单独板级 port。
- 合并工程允许重新建立 Keil 工程，且 Keil 是主要交付入口之一。
- 两个来源的配置、库和模块都要迁移并可追溯；不完善处允许修复和适配。

## 2026-10-01

- 最终只保留一个工程，并且工程实体必须位于 `legacy/nun_dx_original`，不再保留独立 `firmware` 与旧快照双份结构。
- 模块通过一个中央 `.h` 宏配置按需开启；默认只启用测力读取。
- 默认部署不依赖 FreeRTOS，`stm32_template_read()` 必须主动读取传感器，不能依赖后台任务预先更新全局变量。
- 完成交付后删除旧工程、重复库、旧 Keil/CubeMX 文件、F4 草稿和编译产物。
- README 必须包含模块名称、启用宏和引脚定义表。
